# CS-210 Portfolio Reflection – Corner Grocer Project

## Project Summary

The project I selected for my portfolio is the Corner Grocer program written in C++. The purpose of this program was to analyze a grocery store's purchase data by reading information from an input file and displaying the frequency of items purchased. The program allows the user to search for a specific item, display all item frequencies, and generate a histogram showing the number of times each item was purchased. It also creates a backup file containing the frequency data.

## What I Did Particularly Well

One of the strengths of this project was organizing the program into separate functions, making the code easier to read and maintain. I also used a map to efficiently store and retrieve item frequencies instead of relying on multiple loops or arrays. In addition, I included comments throughout the code to explain the purpose of important sections, making it easier for others to understand how the program works.

## Where I Could Enhance My Code

If I were to improve this project, I would add more robust error handling for file operations and user input. For example, I could validate user input more carefully to prevent invalid menu selections or incorrect item names. I could also improve the user interface by making the menu more interactive and adding options to reload different data files. These improvements would make the program more secure, reliable, and user-friendly.

## Challenges and How I Overcame Them

The most challenging part of the project was reading data from a file and correctly storing the information in a map while counting duplicate items. I overcame this by reviewing course materials, practicing with C++ file input/output, and testing my program with different sample files to ensure the counts were correct. I also relied on my instructor's resources, textbook examples, and additional programming references to strengthen my understanding.

## Transferable Skills

This project helped me develop several skills that will be useful in future courses and software development projects. These include using C++ standard library containers such as maps, working with file input and output, creating modular programs with functions, debugging programs, and writing clean, organized code. These skills will transfer directly to larger programming projects.

## Maintainability, Readability, and Adaptability

I made the program maintainable by dividing it into logical functions that each perform a specific task. I improved readability by using meaningful variable names, consistent formatting, and comments where appropriate. The program is adaptable because additional menu options or new features can be added without significantly changing the existing code structure. This modular design makes future updates easier and helps ensure the program remains organized as it grows.
